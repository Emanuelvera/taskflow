# TaskFLOW

Descripción del ProyectoTaskFlow 

Es un sistema de gestión desarrollado por el equipo de NovaTech. El objetivo principal de este proyecto es aplicar conceptos avanzados de programación en C# mediante una aplicación de consola robusta y bien estructurada.

Tecnologías Utilizadas

Lenguaje: C#.
Plataforma: .NET.
Tipo de aplicación: Aplicación de Consola.
Control de versiones: Git / GitHub.

Requisitos Previos
Para poder ejecutar este proyecto, asegúrate de tener instalado lo siguiente:
SDK de .NET (versión 6.0 o superior recomendada).Visual Studio Code o Visual Studio 2022.
Extensión de C# (si usas VS Code).

Cómo Ejecutar el Programa 

Sigue estos pasos para poner en marcha la aplicación en tu entorno local:
Clonar el repositorio:Bashgit clone https://github.com/Emanuelvera/PLA-II.git

Navegar a la carpeta del proyecto:Bashcd taskflow

Restaurar dependencias:dotnet restore
Ejecutar la aplicación:dotnet run
